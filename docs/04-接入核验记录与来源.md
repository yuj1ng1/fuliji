# 接入核验记录与来源

核验日期：2026-10-30（Asia/Shanghai）。以下保留需求分析阶段的历史核验边界；该阶段仅做文档、只读核验和公开校历资料保存。后续 M0 开发与测试结果单独记录。

## 1. 证据的解释方式

- 用户描述与截图：支持用户当时的真实使用体验；不是本工具已独立重复完成全部流程。
- 桌面现场只读核验：支持当前 Edge 登录会话中可访问相应页面；不是安卓 WebView、后台请求或通知监听测试。
- 官方公开资料：支持发布来源和平台能力边界；不是特定学校数据 API 或厂商真机稳定性的保证。
- 工程建议：实现选择与默认值；不能写成学校事实或用户已确认的每一项决定。

## 3. 桌面现场观察

通过现有 Edge 会话只读查看，未输入账号密码、获取 Cookie、充值或修改学校数据。本文件不保存姓名、学号、完整个人课表、具体宿舍或成绩数值。

| 对象 | 观察到的事实 | 结论边界 |
| --- | --- | --- |
| 课表页 | 学年/学期、七天课程表、节次、地点、教师；表中有混合单双周与不连续周次；另有实践课程和其他无固定节次课程 | 可从已渲染页面读取相关结构；未检查数据请求、分页与安卓会话 |
| 教务首页 | 可见校历、课表摘要、成绩摘要、日历和调课提醒 | 首页摘要不代表完整数据；本轮不保存个人内容 |
| 考试查询 | 通过“信息查询 → 考试信息查询”打开；存在学年、学期等条件；列含课程、时间、地点、校区、座号等；当前页面显示“没有符合条件记录” | 尚缺非空样本；未据此推断没有考试或接口已经完整验证 |
| 成绩查询 | 通过“信息查询 → 学生成绩查询”打开；初始显示“请选择筛选条件”；点击当前条件查询后显示“没有符合条件记录” | 证实未查询与查询为空状态不同；没有核验历史学期非空列表/详情/分页 |
| 后勤普通页面 | 存在房间字段 picker-addr 和电量字段 sydl，以及房间用量/充值记录入口；本轮可读取的该页两个字段值为空 | 字段存在不等于已获得电量；不能将空白转换成 0 |
| 后勤已选房间页 | 用户截图及操作描述支持有实际剩余电量，单位为度 | 工具尝试附着该另一个已打开页面时两次超时，未独立读取其中实值；不能把工具超时当作学校服务失败 |
| 课表原始规则 | 出现 1周,5-7周(单),8-10周(双),11-15周 等分段表达；同格多课、周末课、连堂与实践课程均存在 | 规则解析和展示必须覆盖这些情况 |

检查只新增了考试、成绩两个研究页面；完成后关闭这两个页面，原有校园页面保留。未检查浏览历史、支付应用、其他无关应用或账户。
