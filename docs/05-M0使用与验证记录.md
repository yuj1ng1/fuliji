# 榕集 M0：使用与验证记录

日期：2026-10-30。当前版本：0.1.0-m0。

本文件记录首个可安装验证版本，不将需求清单等同于已完成能力。

## 已实现的验证流程

- 今日、课表、校园、账本四个入口；无学校连接时显示明确空状态。
- 应用内打开 WebVPN、教务课表、成绩、考试和后勤页面；学校登录由本人完成。
- 查询后主动“读取并保存”；从限定页面字段取得结果，保存到本机 Room 数据库。
- 课表支持不连续周次、分段单双周、同格多门课程，保留实践/无固定节次课程原始说明。
- 电量读取同时要求有效房间和明确的“度”单位；空白、星号遮罩和无法解释的结果不会变为 0。
- 后勤“房间用量”日明细读取；首页/电量详情显示同房间余额和近 7 个完整自然日的折线图，点选某天可查看原始数值。
- 缺失日期断线、零用量正常保留；不同房间的余额和用量不会拼接。用量原表未标单位，图表保留“原站数值”说明。
- 成绩、考试只保存有明确学年学期、已经查询且确认完整的一页结果；多页或未查询状态不会覆盖旧数据。
- 内置本学年官方校历预览，离线可看、可缩放，并保留官方文章入口。
- 本地手动支出账本；支付通知候选收集、待确认及本人确认后入账。
- 原通知正文不保存；候选记录未确认前不计入支出。失败、待支付和汇总类通知会被过滤。
- 同一通知重复到达不覆盖本人已经修正和确认的账本记录。

## 本版尚未提供

后台定时同步、低电量和课程/考试时间提醒、真正自动入账、第三方历史账单导入、自有 CSV 导出导入、完整周课表格与调课编辑。

本版课表使用可核对的课程列表。它用于先验证真实数据读取，后续在同一工程中扩展正式周视图。

## 手机试用步骤

1. 从本项目提供的版本下载 APK，按手机系统提示完成安装。
2. 打开“校园”，选择需要验证的功能，再打开学校查询。
3. 如果被要求登录，在学校页面输入自己的信息；不需要把密码保存在本应用中。
4. 在学校页面选择学年学期或房间，执行查询，等待页面加载完成，再点击顶部“读取并保存”。
5. 返回原生页面，核对学期/房间、记录数、来源内容和保存时间；退出网络后再次查看本地数据。
6. 账本可先手动记账。支付通知访问需本人从系统设置开启，新候选进入待确认；无需为测试特意消费。

电量图表需要两次明确保存：先在“查询余额”中选房间并保存余量，再进入“查询用量”，在学校“房间用量”中选同一房间、查询并保存。图表使用上海时间今天之前的 7 个完整自然日；学校未给出的日期留空。保存的余额不是实时余额，卡片保留保存时间。

授权只影响通知候选收集，不影响校园查看和手动账本。源应用是否向监听器交付完整通知，需要在具体手机上验证。

如果系统提示“受限制的设置”，可按设备提供的“设置 → 应用 → 榕集 → 更多 → 允许受限制的设置”路径检查，再返回开启通知访问；OriginOS 菜单以实际手机为准。这是 [Android 官方说明](https://support.google.com/android/answer/12623953?hl=zh-Hans)提供的处理路径，不代表已在本机型验证。Android 16 会向普通通知监听器隐藏验证码等敏感内容，参见 [Android 16 CDD 3.8.3.4](https://source.android.com/docs/compatibility/16/android-16-cdd#3834-sensitive-notification-protection)；不能只凭通知栏可见推断监听器必然收到同样内容。

若学校跳转到当前连接范围外的域名，本版会暂停；可反馈域名和提示，但不要发送密码、Cookie、签名 URL 或完整账单。接入范围需核实后再调整。

## 本次真实学校核验

在本人提供信息的授权范围内，完成桌面浏览器 WebVPN 和教务统一认证，未选择长期免登录；未将任何账户信息写入仓库。

随后核对课表 DOM 字段和多课程单元格结构；后勤完成截图所对应房间选择，确认结果呈“剩余量：数值度”。仅记录字段形状，不保存或公开个人课程、成绩、房间或电量值。

这两项是桌面浏览器验证，不是 Android WebView 或 iQOO 真机验证。成绩筛选字段和分页节点已核实，非空列表的整条应用读取链仍待验证。

后续按新增需求实查“房间用量”，确认有日期/用量的逐日列表；只记录了字段结构、条数、日期范围和解析规则是否覆盖，没有把房间与实际用量写入项目。该表有真实历史明细，可以直接提供绘图来源，不需要用余额相减估算。原表没有显示用量单位，暂不补写未确认的单位。

## 本轮界面调整

用户明确选择清爽工具型：浅灰白底、蓝色点缀、信息紧凑。移除大幅标语与粗边框，统一线条图标、字号和底部导航；课表、用电图表/余量、今日支出和校园服务集中展示。公开截图仅采用空状态或明确标注的合成数据；合成数据只在测试安装包生成，不进入正式应用的数据库。

## 本地构建

配置受支持的 JDK 和 Android SDK 36，在本机不提交的 local.properties 中指定 sdk.dir，随后使用：

    .\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest
    .\gradlew.bat :app:lintDebug

如当前网络无法下载某个 Central 工件，可选用 scripts/Cache-MavenArtifact.ps1。缓存位于 .local/maven-cache，读取仓库范围只允许官方 Central 域名；普通环境不需要此工具。
